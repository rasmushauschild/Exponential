# Exponential — CLAUDE.md

Team planning app (Electron + React + TS + Vite, Supabase backend). Repo: https://github.com/rasmushauschild/Exponential (public). Owner: Rasmus Hauschild <r.hauschild@airyautomotive.com>.

## What it is
- **Master plan** (top): zoomable/pannable timeline. Projects = outlined pastel bars in **group** sections (group = name+colour; ungrouped = grey, last section). Deadlines = black dots on one row (hover row to add). Blue **week band** (drag = snap-animated; label opens that week's **Retro**: fixed structure (no date-range line under the Week title) Priorities this week (RetroList rows: a plain position NUMBER (.rl-num) plus the manual P1-P3 level chip (tap cycles, colors red/orange/grey), per-priority assignees stored as a " @[id|id]" line suffix (overlapping avatar stack flush right, '+' sits left of it and opens a who-menu portal), stored as "P1 …" lines, reached/missed = "P1✓ …"/"P1✗ …" — ✓ fires green confettiBurst, ✓/✗ live in a ZERO-WIDTH .rl-marks overlay (no reserved space; text pads right only on hover or when a mark is set), NO delete × (Backspace on empty removes); rows drag-reorder via chip/dot handle (src/rowDrag.ts dragRows)) / OKR confidence (each KR = rounded box (bg reacts via :has — deep space while warping, darker per level (w7-w10 classes), dark red #2b0d0e while ≤3); −/+ stepper w/ number in a tinted chip (like P chips; red≤3/amber≤6/green/blue at 10; glows harder per warp level), + thumps (step-pop), − shakes (step-shake); warp starfield ≥7 inside the box (2-segment solid strokes, NO gradients/shadowBlur — they lag; length/speed scale w/ score, hyperspace blue-white at 10, both-end fade), chip breathes red ≤3; scores CARRY FORWARD — a week inherits the latest earlier confidence per KR (carriedConfidence from App, merged under this week's own; first edit persists all, Lock freezes them)) / Improvements (plain RetroList rows, stored as lines; 'focus' answers legacy) / Health (matrix: avatar header row — own bright, others faded — with one g-y-r dot per person per question, own column clickable; carried Improvements quoted next week; retro has NO Send-to-Agent; Lock button at the foot freezes the page — snapshots template+people into answers (locked/lockedAt/people), renders read-only, unlockable). Retro type scale: 11px caps titles, 13px/500 content, 12px tabular numbers; each section is a white card (bg --panel, radius 14, 0.5px --rim + soft lift); marked priority rows + P chips use the bar recipe (tint fill, same-hue darker inset edge, --rim); KR boxes bg --frost + --rim. Objective+KRs+health checks = `retroTemplate` on the team (Team settings; TemplateList rows styled identically to retro lists — dot drag handle, hover ×, ghost + Add; GrowInput re-fits via ResizeObserver on width change), snapshotted into each retro's answers so past weeks freeze; legacy retroFields answers render read-only). Red today line. Vertical scroll when rows overflow. PERF: wheel pan/zoom is rAF-coalesced (pendingView ref — NOT viewRef, which re-syncs from state every render and a touchView re-render would clobber it); the dot grid is a composited .tl-dots child translated on the GPU; and ALL day-positioned chrome + bars live in transform-panned wrappers (.tl-pan for header chrome/band/deadlines, .tl-pan-top for the today line (z5), .tl-scrollv for vertical scroll inside .tl-lanes, .tl-panh around the bars) — children use STABLE epoch-relative lefts (epochRef anchors coords so layer bounds stay small), so a pan/scroll frame is a handful of transform writes, no layout/paint. Months stay origin-based outside (their sticky clamp needs viewport coords). Bars RENDER sorted by start asc, end desc → later-start (and engulfed) bars paint on top; selected bars get zIndex 3. Click empty lane = create project w/ inline name. Hovering a group's LABEL ROW shows the ghost ON that row and clicking creates at the group's TOP (existing lanes shift down — slotAt returns header:true); a bar DROPPED on the label still appends. Escape relocks the plan. Drop a bar on a group label = append to that group. The blue week label drags the band (a still tap opens the retro). Resize grips extend 8px OUTSIDE each bar (edgeHitAt on data-pid rects — grabbing beside a pill no longer creates a project; ghost suppressed near grips). Inline names (create/rename) also commit on click-away (capture-phase pointerdown → blur; the drag surfaces preventDefault, so blur alone never fired). Right-click a bar (or a week task row) = Duplicate + Delete. The plan relocks ONLY on window blur / Team settings / team switch (not on any outside click). Group labels drag vertically to reorder sections — other sections glide aside live (labels+bars translateY, drop always matches the preview; groupDragPreview in BigPlan) (unlocked only; tap still opens the group sheet). The label's colour dot becomes a chevron on hover: collapses the group (per-machine, localStorage exponential-collapsed; collapsed = 32px header only, bars hidden, toggling animates (240ms fold window: .tl-lanes.glide rows glide top, toggled bars fade out/in), invisible ::after enlarges the chevron hit area, not a drop/create target, its bars leave the multi-selection, in-flight rename committed via blur first).
- **Week view** (bottom): rows = tasks (list left, 7-day blocks right). Backlog = undated tasks, faded at bottom, shown every week; click a day on its row to schedule. Drag blocks horiz = move/stretch; vert on row = reorder within day (drop is EXACT: reorderTask takes afterId, not a step delta — hidden done/deleted rows made multi-step drags snap wrong). Anyone edits anyone's week with full freedom (only pending invitees are read-only); owners get task-changed notifications for status/date/rename changes made by others. Review-request rows keep the dashed look (62% status colour, no longer faint); tasks merely added by others render like normal tasks + creator chip. Kept fresh via subscribeTeam REALTIME per foreign team + a ≥5min-throttled focus refetch — the original 60s/every-focus full-team polling helped blow the Supabase egress quota; clicking a row switches team & opens it. Status dot menu (todo/progress/review/done/cancelled; hover "Needs review" → pick reviewer). Person dropdown (Me first, then alphabetical). Enter after naming a task chains a new one. Trackpad swipe = prev/next week (one flip per gesture, no rubber band). Past weeks: hover an unfinished task → "Move to this week" pill sends it to the top of the backlog. Floating grey "+ Add task" bottom-left.

- **Sidebar** (72px rail, hover expands to 232px pushing content): team list (click=switch, hover cog=Team settings page: rename, image icon upload, retro questions, members/invites/roles, delete team), Plan, Inbox (real notifications), Check-for-updates, dark mode toggle, account.
- **Menu-bar widget** (macOS Tray, plan glyph): frameless popover with only my week; opens ready-to-type (new task at TOP of backlog); "Open app" button; hides on blur. ## Architecture
- `electron/main.cjs` — windows (transparent+CSS-rounded on mac, radius 26 in `#root.mac-window`; traffic lights 14,14), Tray+widget (`?mode=widget`, `--widget` arg), IPC (data load/save broadcast, google:*, update:*), electron-updater (check 8s + 2h, autoDownload, installs on quit; log: userData/updater.log).
- `electron/google.cjs` — OAuth PKCE via system browser + loopback; tokens in userData/google-tokens.json; **id_token refreshed with access token, validity from its own exp**; incremental `grantCalendar()` (calendar.readonly is NOT granted at first sign-in — Google checkbox). Client creds: `electron/google.client.json` (git-ignored, bundled; example file beside it).
- `src/store.ts` `useData()` — dual mode: **local** (browser preview: localStorage workspace w/ sample data) / **cloud** (after `connectCloud()`). Cloud: one team at a time → `Data` shape; every `update(fn, coalesceKey?)` diffs prev/next via `cloud.persistDiff` into row writes; realtime `subscribeTeam` → debounced reload, **deferred while writes in flight AND discarded if editSeq changed during fetch** (typing race!), and DEFERRED WHILE THE WINDOW IS HIDDEN (visibilitychange catches up — the pre-loaded widget used to refetch+rerender on every teammate edit all day; battery). Undo = reverse diff. Team list re-checked on focus + 30s (invites). NO side effects inside React setState updaters (Strict Mode runs them twice — caused real bugs).
- `src/cloud.ts` — supabase client (URL+publishable key hardcoded), row↔model mapping, `ensureSession` (Google id_token → signInWithIdToken, retry with forced refresh; recovers stale sessions via signOut+retry in store; loadTeam/persistDiff pre-flight ensureSession — a session that died mid-run (sleep past expiry, backend outage blocking refresh) otherwise makes every write bounce off RLS as anonymous until restart), `ensureProfile` rpc, `onPersistError` → red toast in App. **Notifications: plain INSERT (upsert trips the own-rows UPDATE policy!), updates only for read-marking.** CONCURRENCY: existing rows persist COLUMN-LEVEL (changedCols → .update() with only the fields this client changed; new rows insert whole) and retros go through mergeRetroWrite (read current row, overwrite only the answer KEYS changed locally; the health key merges per PERSON) — before this, full-row/full-jsonb upserts made simultaneous editors overwrite each other constantly. Same-field simultaneous typing is still last-writer-wins.
- `src/taskOps.ts` — shared pure ops (addTask w/ 'start'|'end' + link {projectId|parentId}, renameTask (notifies), patchTask (owner/review notifications), reorderTask (groups by person+date ONLY), claimTask/unclaimTask, completeReview/denyReview, softDelete/purgeTrash). **Deletes are soft** (deletedAt, 7-day trash in Team settings → Recently deleted; App filters via `live`, purge on launch).
- `mcp/` — MCP server (stdio): Claude reads/edits the plan as the signed-in user. Ships INSIDE the app (extraResources; **run `cd mcp && npm install` before building a release**); Team settings → "Connect to Claude" registers it in Claude Desktop's config + `claude mcp add` (login shell), with the app binary as Node via ELECTRON_RUN_AS_NODE. Auth: bootstraps a Supabase session from userData/google-tokens.json id_token, then self-refreshes (mcp-session.json). Master-plan tools gated on userData/shared-state.json planUnlocked, written by the app (IPC state:set) whenever the Unlock toggle or team changes.
- `src/App.tsx` — shell, sign-in gate (mandatory Google), no-team screen, sheets (project/deadline/group/team/settings), notifications wiring, prefs in localStorage `exponential-layout` (weekH 400, detailW 415, theme, calendar — default ON, allTeams). Calendar auth loss on MY calendar (401/403/insufficient) shows 'Calendar access was lost' + a Reconnect pill (grantCalendar again). macOS notifications off (com.apple.ncprefs delivery-style bits, checked once per launch on first notify, packaged only) → toast with an Open-Settings button.
- `src/BigPlan.tsx` (sections/lanes math, slotAt, drags), `src/WeekPlan.tsx` (rows, swipe, StatusMenu portal — all popups render to document.body, positioned from captured rects; **capture getBoundingClientRect BEFORE setState**, event is recycled), `src/BlockEditor.tsx` (blocks ↔ markdown, task line = `- [ ] Title <!--task:uuid-->`, trailing empty p always), `src/DetailPanel.tsx`, `src/TeamPage.tsx`, `src/Widget.tsx`.
- Click-away listeners use **pointerdown** (mousedown is suppressed by preventDefault on drag surfaces). Drag regions: `.shell`/heads drag; sheets/menus/panels no-drag (buttons in drag regions don't click!).

## Build / release
- UI zoom default 0.9 (stored 0.8 one-time-bumped via zoom.json `bumped9`).
- Dev: `npm run dev` (or vite via .claude/launch.json + `VITE_DEV_SERVER_URL=http://localhost:5173 npx electron .`). Browser preview = local data mode, no Google.
- Release: bump version, commit, then `APPLE_KEYCHAIN_PROFILE=exponential GH_TOKEN=$(gh auth token) npm run release` (= electron-builder --mac --publish always, config `electron-builder.config.cjs`). **arm64 only** (dmg+zip; zip+latest-mac.yml required by updater). Signing: "Developer ID Application: Rasmus Hauschild (TSH9XSMSE4)" in keychain; notarization via keychain profile `exponential` (skipped if env absent → Gatekeeper blocks + translocation breaks updates — always notarize).
- **Windows too, every release** (there are Windows testers; without latest.yml their update button 404s): `GH_TOKEN=$(gh auth token) npm run release:win` (nsis x64, unsigned, builds fine on macOS) **BEFORE publishing the draft** — electron-builder refuses to upload into an already-published release ("existing type not compatible"). If that happens: upload manually with DASHED names (`cp "Exponential Setup X.exe" Exponential-Setup-X.exe` — latest.yml references the dashed name, gh would mangle spaces to dots) via `gh release upload vX Exponential-Setup-X.exe Exponential-Setup-X.exe.blockmap latest.yml`.
- electron-builder creates DRAFT releases: publish by PATCHing the draft (`gh api -X PATCH .../releases/<id> -f draft=false`, then `-F make_latest=true`). **Never delete drafts before checking which release holds the assets** (deleted 0.2.5's assets that way once).
- Icon: `build/` — Icon Composer bundle compiled with `xcrun actool` → icon.icns + Assets.car (CFBundleIconName "exponential"); tray = AppKit-drawn plan glyph template PNGs.

## Conventions & gotchas
- All colours via CSS tokens incl. `--line` (hairline outlines) and `--ov-*` overlays. FLAT supabase-style theme (NO glass/blur/gradients): light = #f0f0f3 ground; panels = Finder-glass (--frost almost-white inner + blur 30, --edge white outline ring, --shadow soft drop below; menus/sheets/fab/week-pills use --edge too); --line rgba(0,0,0,.09) for inner hairlines; dark = NEUTRAL greys (bg #0b0b0b, panels #141414, frost rgba(20,20,20,.85) — deliberately no blue/purple cast), --line white .1; blue --accent (#0a84ff light / #3b9cff dark), blue week band + --sel-blk; small radii (panels 12 via --radius-xl, menus/retro cards 10, bars/pills 7-8, blocks 6); --shadow none, menus = hairline + --menu-shadow; bars/blocks = tinted inner (::before 0.16/0.24/0.32 hover/selected) + hairline border, selected = inset text-3 ring; pills/chips/date-pills/fab/toolbar buttons = panel bg + hairline; .pill.toggle.active = accent bg + white text; white default object colours (NO_GROUP_COLOR + STATUS_COLOR.todo = #fff); PROJECT_COLORS = vivid Apple-ish set, legacy muted hexes remapped at render via crispColor(); dark mode `[data-theme='dark']`; panels must fit in 18px shell padding or they clip.
- Dates are `YYYY-MM-DD` strings, day math via dayIndex/fromDayIndex (UTC-based) in src/dates.ts; weeks start Monday.
- uid() = crypto.randomUUID (DB needs uuids).
- Commit style: descriptive one-liner + `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`; push after every accepted change; git identity set per-command with -c.
- Hidden browser-preview pane throttles timers & freezes animations/focus events — use MutationObserver waits and fake performance.now in tests; don't trust screenshots mid-animation.
- User prefers: compact minimal UI, no stray gaps, quiet grey buttons, everything pushed (not overlaid), releases with few assets.
